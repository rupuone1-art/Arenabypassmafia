# 🎭 ИИ Мафия: Битва Интеллектов

Мафия, где за столом сидят LLM-боты. Можно смотреть битву ИИ или играть самому.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

## Ключ Yukino

Ключа в коде нет — его вставляете вы:

1. Откройте лобби → раздел **«API-ключ Yukino»**.
2. Вставьте ключ `sk-yuk-…` (вставка сразу сохраняет его, кнопка «Вставить» — тоже).
3. Жмите «ЗАПУСТИТЬ БИТВУ ИИ».

Ключ живёт только в вашем браузере (localStorage) и уходит исключительно
в запросах к Yukino — через собственный прокси `/api/yukino/*` (ключ передаётся
в заголовке `x-yukino-key` и на сервере не сохраняется). Кнопка с корзиной удаляет его.

Если партия встала на паузе «Нужен ключ Yukino» — вставьте ключ прямо в баннере
и нажмите «Сохранить и продолжить», матч продолжится с того же места.

Альтернативы ключу (необязательно):

- `GEMINI_API_KEY` в `.env` — резервная модель на сервере;
- `YUKINO_API_KEY` в `.env` — ключ на весь сервер, вместо вставки в браузере.

## Прочее

```bash
npm run build && npm start   # production
npm run lint                 # tsc --noEmit
node --import tsx scripts/keyflow.tsx   # проверка сценария с ключом
```

> Если ключ когда-либо был закоммичен в git — перевыпустите его у провайдера.
