# 🎭 ИИ Мафия: Битва Интеллектов

Психологическая ролевая игра «Мафия», в которой за столом сидят LLM-боты:
они спорят, вскрываются, лгут, голосуют и убивают ночью. Можно наблюдать
за битвой ИИ или сесть за стол самому.

<p align="center">
  <b>React 19 · TypeScript · Vite 8 · Express · Tailwind 4 · Gemini / Yukino / локальный движок</b>
</p>

---

## Что умеет

- **Режим наблюдателя** — 4–8 ИИ-игроков играют сами, вы видите их роли, тайные мысли 🧠 и весь ход партии.
- **Режим игрока** — вы занимаете место за столом, получаете роль и играете против ботов.
- **Чтение мыслей** — скрытый `analysis` каждого бота показывается отдельно от его публичной речи (никаких «утечек» мыслей в чат).
- **Журнал отладки** — по каждому ходу видно системный промпт, пользовательский промпт, сырой ответ модели и распаршенное решение.
- **Ночные роли** — мафия, шериф, доктор, мирные; казнь по большинству голосов, проверки шерифа, лечение доктора.
- **Три провайдера «интеллекта»** с автоматическим падением на встроенный движок:
  `Gemini → Yukino → локальный ИИ`.

## Быстрый старт

```bash
npm install
cp .env.example .env     # необязательно: без ключей игра тоже работает
npm run dev              # http://localhost:3000
```

Готово: без единого ключа матч запускается и доигрывается до победы —
ботов «думает» встроенный движок `src/game/localBotAI.ts`.

### Production

```bash
npm run build
npm start                # Express отдаёт dist/ + API-маршруты на PORT (3000)
```

## Провайдеры ИИ

| Провайдер | Переменная | Что даёт |
|---|---|---|
| **Gemini** | `GEMINI_API_KEY`, `GEMINI_MODEL` | Живые, нешаблонные речи и дедукция |
| **Yukino** | `YUKINO_API_KEY`, `YUKINO_BASE_URL`, `YUKINO_MODEL` | OpenAI-совместимый шлюз, проксируется сервером |
| **Локальный движок** | — | Работает всегда, без сети и ключей (эвристики + шаблоны) |

`AI_PROVIDER=auto | gemini | yukino | local` — принудительный выбор.
`AI_PROVIDER=local` полностью отключает сетевые вызовы (удобно для демо и CI).

**Ключи никогда не попадают в браузер**: клиент общается только со своим сервером
(`/api/gemini/*`, `/api/yukino/*`), а сервер подставляет ключ из окружения.
Текущий режим виден в интерфейсе — бейдж «Gemini / Yukino / Локальный движок»
в лобби и в шапке партии.

Проверить, что реально активно:

```bash
curl -s localhost:3000/api/ai/status
# {"provider":"local","gemini":false,"yukino":false,"model":"local-engine"}
```

Отключить внешние модели на один запуск можно и без сервера:
`http://localhost:3000/?ai=local`.

## Как это устроено

```
src/
├── App.tsx                 # машина состояний партии: ночь → день → голосование → финал
├── game/
│   ├── mafiaEngine.ts      # чистая логика: роли, голоса, ночные исходы, промпты, парсинг JSON
│   ├── localBotAI.ts       # эвристический «мозг» ботов (fallback без LLM)
│   └── *.test.ts           # юнит- и симуляционные тесты
├── services/
│   └── aiClient.ts         # цепочка провайдеров + ограничитель параллельных вызовов + fallback
└── components/             # лобби, модалки, звук, бейдж провайдера
server.ts                   # Express: секреты, прокси к моделям, /api/ai/status, Vite/статика
```

Принципы, на которых держится код:

1. **Логика игры отделена от моделей.** `mafiaEngine` — чистые функции, их можно тестировать без сети.
2. **Модель возвращает JSON, а не «свободный текст».** Речь (`say`) и мысли (`analysis`)
   разделены, поэтому скрытый расчёт бота не утекает в общий чат.
3. **Ответ модели всегда валидируется.** ID цели сверяется со списком живых кандидатов;
   при некорректном ответе срабатывает детерминированное разрешение по имени → по упоминанию → по первому кандидату.
4. **Игра не зависает.** Любой сбой провайдера заканчивается переходом на локальный движок,
   а не бесконечным ожиданием; есть системная пауза с кнопкой «Повторить ход».

## Тесты

```bash
npm test        # 18 тестов: правила игры, промпты, локальный ИИ, смоук UI в jsdom
npm run e2e     # полная партия в jsdom на локальном движке (~20 c), печать лога и победителя
npm run typecheck
```

Что покрыто:

- распределение ролей, условия победы, разрешение голосов и ночных действий;
- изоляция приватных данных в промптах и отсутствие утечки мыслей в речь;
- локальный ИИ: мафия не бьёт своих, шериф не проверяет дважды, боты не голосуют в себя,
  шериф закрывает чёрную проверку, решения детерминированы;
- симуляция 14 полных партий: игра всегда завершается, и обе стороны способны победить;
- монтирование UI в jsdom, клик по «ЗАПУСТИТЬ БИТВУ ИИ» и реальные первые ходы.

## Частые вопросы

**Реплики ботов шаблонные.** Значит, внешняя модель не подключена и работает локальный
движок — посмотрите бейдж провайдера и `/api/ai/status`, затем задайте `GEMINI_API_KEY`
в `.env` и перезапустите сервер.

**Партия встала на паузе с предупреждением.** Все провайдеры ответили ошибкой, а локальный
движок вернул пустую речь. Нажмите «Повторить ход»; журнал отладки покажет сырой ответ модели.

**Порт занят.** `PORT=4000 npm run dev`.

**Нужен доступ с телефона / через туннель.** Сервер слушает `0.0.0.0`, а Vite принимает
любой `Host` (`server.allowedHosts: true`), поэтому preview-домены работают без правок.

## Безопасность

- Секреты живут только в `.env` (в `.gitignore`) и читаются исключительно сервером.
- В репозиторий не должны попадать реальные ключи. Если ключ когда-либо был закоммичен —
  считайте его скомпрометированным и перевыпустите у провайдера.
