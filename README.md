# Arena: готовые скиллы и память между сессиями

Здесь собраны **существующие** открытые скиллы и инструменты для работы с агентом Arena: Qawa, Superpowers, Anthropic Skills, Vercel Agent Skills и Skills CLI. Оригинальные файлы находятся в `third_party/`; они не выданы за самостоятельно придуманные скиллы. Инструкции предназначены для ИИ: агент сам выбирает нужный скилл, пользователю не нужно знать их названия или настраивать их вручную.

## Начать в новом чате

Подключи репозиторий и отправь агенту:

```text
Прочитай AGENTS.md и .qawa/STATE.md, затем используй подходящие готовые скиллы из репозитория.
```

Дальше можно писать по-русски: «найди и исправь ошибку», «составь план», «проверь код» или «сделай интерфейс». Агент выберет оригинальный скилл по смыслу и прочитает его файл. Полная шпаргалка — [.agents/ARENA_SKILLS.md](.agents/ARENA_SKILLS.md).

**Важно:** это не встроенные плагины Arena. Автоматическое чтение `AGENTS.md`, регистрация slash-команд, хуки и запуск подагентов не гарантируются. Если агент не подхватил инструкции, попроси его прочитать файлы явно. Файлы и журнал появятся в новой сессии только если доступны в выбранной ветке репозитория.

## Что внутри

- **Qawa** — адаптация Superpowers под среды без нативного загрузчика скиллов; в том числе файловый журнал `.qawa/STATE.md`.
- **Superpowers** — оригинальные инструкции для планирования, отладки, TDD, ревью и проверки результата.
- **Anthropic Skills и Vercel Agent Skills** — оригинальные скиллы с разрешающими лицензиями для дизайна, React и других задач.
- **Skills CLI** — оригинальный исходный код и зафиксированный пакет `1.7.4`.
- **Office Agent Skills и OpenAI PDF** — открытые альтернативы для документов.

Источники, версии и исключения: [third_party/README.md](third_party/README.md) и [upstream-lock.json](upstream-lock.json). Четыре документных скилла Anthropic не скопированы: их лицензия запрещает копирование и распространение; часть скиллов Vercel и один Anthropic не скопированы из-за неуказанной лицензии.

## Полезные команды

```bash
python3 tools/skills_catalog.py list
python3 tools/skills_catalog.py suggest "исправь ошибку в кнопке"
python3 tools/skills_catalog.py show qawa/systematic-debugging
python3 third_party/qawa/qawa doctor
python3 third_party/qawa/qawa state
python3 -m unittest discover -s tests -v
```

Каталог и Qawa требуют Python 3.9+ и не обращаются к сети. Это вспомогательный индекс и оригинальный инструмент, а не автоматический загрузчик скиллов Arena. Зависимости для документов и Skills CLI могут потребовать отдельной установки; подробности и ограничения — в шпаргалке.
