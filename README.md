# 🎭 ИИ Мафия: Битва Интеллектов

> Мафия, где вместо друзей за столом сидят LLM, которые уверены, что умеют
> играть в мафию. Спойлер: они не умеют. Но очень стараются, и это смешно.

**Что это:** браузерная мафия. Ты либо смотришь, как шесть-восемь ботов
подозревают друг друга в интеллектуальном смысле, либо садишься за стол сам
и получаешь роль. Ночью кого-то убивают, днём кого-то казнят, вечером кто-то
пишет «я так и знал».

## 🔑 Ключ Yukino (да, он нужен, и нет, я его не знаю)

Ключа в коде нет. Ни в переменных, ни в комментариях, ни «на всякий случай
в base64». Сам ключ ты добываешь сам, сам же и вставляешь:

1. Открываешь лобби → раздел **«API-ключ Yukino»** (он жёлтый, его сложно не заметить).
2. Вставляешь `sk-yuk-…`. Всё, он уже сохранён — вставка сохраняет автоматически,
   потому что мы знаем, как люди ненавидят лишние кнопки.
3. Жмёшь **«ЗАПУСТИТЬ БИТВУ ИИ»**.

Ключ сидит только в твоём браузере (localStorage) и уходит исключительно в
запросах к Yukino через наш прокси `/api/yukino/*`. Сервер ключ не хранит,
не логирует и не продаёт (он вообще ничего не умеет продавать).

Партия встала и пишет «Нужен ключ Yukino»? Вставь ключ прямо в баннере и жми
**«Сохранить и продолжить»** — матч поедет с того же хода. Лобби найдёшь сам.

Корзина рядом с ключом = «забудь меня», ключ удаляется из браузера.

Альтернативы для тех, кто любит `.env`:
`GEMINI_API_KEY` — резервная модель на сервере, `YUKINO_API_KEY` — ключ на весь сервер.

## 🔗 Хочу открыть по ссылке, без Termux

Сразу важное: **чистый статический хостинг (GitHub Pages, Netlify Drop) не подойдёт.**
Yukino отдаёт `Disallowed CORS origin` — браузеру с чужого домена он отвечать не будет
(проверено запросом с `Origin: https://rupuone1-art.github.io` → `HTTP 400`).
Поэтому нужен **хоть какой-то серверный прокси** — он в проекте уже есть,
просто его надо куда-то поставить. Три бесплатных пути, ни один не требует Termux:

| Куда | Сколько кликать | Ссылка получится |
|---|---|---|
| **Render** (проще всего) | войти через GitHub → New → Blueprint → выбрать репозиторий | `https://ai-mafia-arena.onrender.com` |
| **Vercel** | войти через GitHub → Add New → Project → Import | `https://<проект>.vercel.app` |
| **Railway / Fly / VPS** | любой Node-хостинг | своя ссылка |

Готовые конфиги уже лежат в репозитории:

- `render.yaml` — blueprint для Render (бесплатный план, `npm ci && npm run build`, `npm start`);
- `vercel.json` + `api/index.ts` — serverless-вход, тот же Express-апп из `server/app.ts`.

Ключ Yukino при этом всё равно можно не класть в переменные окружения — игрок
вставляет его в интерфейсе, а сервер просто пробрасывает заголовок в Yukino.

**Важно про Render free:** сервис засыпает после ~15 минут простоя, первый заход
после сна грузится ~30 секунд. Это нормально, не пугайся.

**А пока ничего не задеплоено** — игра живёт в preview-песочнице Arena,
ссылка на неё есть в интерфейсе сессии. Она умирает вместе с сессией, поэтому
для постоянной ссылки нужен один из вариантов выше.

## 🧠 Как это играет (и почему иногда тупит)

Бот получает роль, психотип, манеру речи, список живых с ID, историю голосований
и хронологию споров. Всё, что он пишет, делится на две части:
`say` — что он говорит вслух, `analysis` — что он *на самом деле* думает.

Вторая часть — это чистое золото:

> «Мои подозрения: Борис (0.6), Дина (0.4).»

Никакой интриги, никакой дедукции — просто числа. Зато весело смотреть,
как бот с уверенностью экстрасенса говорит «я пересмотрел весь круг»,
хотя пересмотрел он только вывод собственной модели.

## 🙃 Троллинг-секция, или FAQ

**«Боты голосуют как стадо»**
Поздравляю, ты открыл теорию игр. У них одинаковый промпт, одинаковые вводные
и одинаковый бэкенд. Стадо — это не баг, это emergent behavior. Скажи спасибо,
что они не создали профсоюз.

**«Бот написал, что голосует в Бориса, а руку поставил в Дину»**
Он не врёт. Он креативный. Модель — не калькулятор, а творческое существо
с вольным отношением к инструкциям. Поэтому ID цели сверяется с реальным
списком кандидатов, и партия не разваливается. Почти всегда.

**«Он сказал "я шериф" на первом ходу без проверок»**
Классика. Мафия тоже так делает. А если это делает настоящий шериф — это уже
не баг, а трагедия.

**«Бот выдал себя, сказав "я мирный, честно"»**
Доверять словам мафии — вообще базовая ошибка. Тут в игре и боты такие же
наивные, как люди, которые верят, что «честно» в мафии значит что-то.

**«Ответы шаблонные, как будто писал стажёр в первый день»**
Ключ не подхватился. Смотри на плашку «не задан» в лобби и на бейдж провайдера
в шапке партии. Нет ключа — игроков на поле нет, играет пустота.

**«Партия встала на паузе и ничего не происходит»**
Так задумано: это не зависание, это вежливое «модель недоступна, вот кнопка».
Жми «Повторить ход» — партия продолжит, а не начнётся заново.

**«А можно как-то по-честному, без ИИ, чтобы я выиграл?»**
Можно: нажми на ключ, подожди паузу, а потом просто не вставляй его обратно.
Ты победил. Поздравляем, Жюри в восторге.

**«Я казнил мирного, а мафия победила. Это баг?»**
Нет, это балет. Ты и есть баг.

## 🛠 Для тех, кто полезет в код

```bash
npm run build && npm start   # production
npm run lint                 # tsc --noEmit (проходит, я проверял)
node --import tsx scripts/keyflow.tsx   # 11 проверок сценария с ключом
```

Логика партии (`src/game/mafiaEngine.ts`) — чистые функции: роли, голоса,
ночные исходы, парсинг JSON. UI (`src/App.tsx`) — машина состояний
ночь → день → дебаты → казнь → финал. Ключ (`src/services/keys.ts`) — обычный
localStorage, потому что не надо усложнять там, где люди просто вставляют строку.

## 📜 Дисклеймер

Игра симулирует убийства, интриги и подозрения. Всё это происходит в чате
между текстовыми строкками и не имеет отношения к реальным людям.

⚠️ **Если ключ когда-либо попадал в git — перевыпусти его.** История коммитов
помнит всё, даже то, что ты удалил.

Боты не умеют держать poker face. Зато умеют писать «я так и знал» после
собственного провала. Береги их, они стараются. 🔪🌙
